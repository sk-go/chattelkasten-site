# chattelkasten.com

Statische Projekt- und Methodikseite für **Chattelkasten** (gehostet über GitHub Pages).

- **Live:** https://chattelkasten.com
- **Struktur:** Reines statisches HTML/CSS/SVG (`index.html`, `styles.css`, `favicon.svg`, `CNAME`, `.nojekyll`) — ohne Build-Schritt, ohne Cookies, ohne Tracking und ohne externe CDNs.

## Aktualisieren

Änderungen an `index.html` oder `styles.css` einfach committen und nach `main` pushen — GitHub Pages veröffentlicht den neuen Stand innerhalb von ca. 30–60 Sekunden automatisch unter https://chattelkasten.com.
