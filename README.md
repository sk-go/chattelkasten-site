# chattelkasten.com

Statische Projekt- und Methodikseite für **Chattelkasten** (gehostet über GitHub Pages).

- **Live:** https://chattelkasten.com
- **Struktur:** Reines statisches HTML/CSS/JS/SVG (`index.html`, `styles.css`, `app.js`, `favicon.svg`, `CNAME`, `.nojekyll`), ohne Build-Schritt, ohne Cookies, ohne Tracking und ohne externe CDNs.

## Aktualisieren

Änderungen an `index.html`, `styles.css` oder `app.js` committen und nach `main` pushen. GitHub Pages veröffentlicht den neuen Stand innerhalb von ca. 30 bis 60 Sekunden automatisch unter https://chattelkasten.com.
